## 地区工作簿怎么填

1. 打开自己的工作簿，先看说明和主检查页。每家有OSM、Overture两项，40项对应20家非试点餐厅。
2. A至H列是目标、AI建议和疑点。在Evidence页按任务编号查名称、地址、电话、距离和ID。建议不能直接当成已核实答案。
3. I列填人工结果；J列写具体依据和接受或更正的完整记录ID；K列填实际核对人，L列填实际日期。不要补写来源没有的楼层、铺号或电话。
4. `Confirmed`须支持同一分店并明确一个来源记录ID；`Uncertain`表示证据不足或冲突未解；`No counterpart confirmed`表示此次未确认对应，不等于来源未收录。拒绝首条候选后继续检查合理候选。
5. 另存完成版，返回原文件。ID保留文本，不转换为数字或科学计数法。完成计数只检查填写，不证明内容正确。
